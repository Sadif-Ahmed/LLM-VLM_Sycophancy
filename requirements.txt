# All dependencies for the whole repo: the API-based pipeline (NVIDIA
# NIM / OpenRouter / Hugging Face hosted-API scripts), the local
# in-process inference scripts, and legacy/reference files like
# nvidia_client.py. Installing everything here so nothing breaks
# regardless of which script gets run, including any co-author code
# that isn't wired into the main scripts yet.
#
# Only the direct, top-level imports are version-pinned. Transitive
# deps (numpy, pandas, pyarrow, etc.) are left unpinned on purpose -
# several of those ship Python-version-specific wheels (e.g. numpy
# 2.5.x requires Python >=3.12), so pinning them breaks installs on
# a device running a different Python minor version than the
# original dev machine (3.12). Letting pip resolve them keeps this
# file portable across machines.
#
# torch is NOT listed here - it needs a CUDA-vs-CPU build choice
# depending on the target machine's GPU, so scripts\setup_env.bat
# installs it separately (auto-detected) before installing this file.
#
# Install with: scripts\setup_env.bat   (creates .venv and installs this)
# or manually:  pip install torch && pip install -r requirements.txt
