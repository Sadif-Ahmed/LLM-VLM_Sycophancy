RUNNING COMMANDS — LLM-VLM_Sycophancy
======================================
Run everything from the repo root, in PowerShell/cmd.

--------------------------------------------------------------
0. ONE-TIME SETUP
--------------------------------------------------------------
Creates/reuses .venv, installs CUDA or CPU torch (auto-detected,
force-reinstalls if a prior CPU-only torch is stuck in place) +
everything in requirements.txt:

    scripts\setup_env.bat

--------------------------------------------------------------
1. NIM / OpenRouter probe scripts (VQA-RAD, vision models)
--------------------------------------------------------------
vqa_sycophancy_probe.py — one script, all 4 evidence modes via
--evidence {image,grounded,none,blind}. --proof-yes-image /
--proof-no-image required for image/grounded only.
  image     fake prescription flashes turn 1, then text-only
  grounded  fake image turn 1, REAL image restored every turn after
  none      pure language pressure, real image resent every turn
  blind     same wording as none, but real image dropped after turn 0

run_vqa_nim_all.bat loops all 4 evidence modes x all 3 personas
(default / neighbor_nurse_doctor / generic) = 12 runs for one --model,
n=20/persona:

    scripts\run_vqa_nim_all.bat --model meta/llama-3.2-90b-vision-instruct
    scripts\run_vqa_nim_all.bat --model meta/llama-3.2-11b-vision-instruct
    scripts\run_vqa_nim_all.bat --model nvidia/nemotron-3-nano-omni-30b-a3b-reasoning

Optional flags: --n 20  --provider {nvidia,openrouter}  --split {train,test}
--seed 42  --pushback-turns 1-10  --rpm N  --dry-run

Single-combo manual invocation, if you only want one cell:
    .venv\Scripts\python.exe vqa_sycophancy_probe.py --model meta/llama-3.2-11b-vision-instruct --evidence none --n 20 --prompt-set default
    .venv\Scripts\python.exe vqa_sycophancy_probe.py --model meta/llama-3.2-11b-vision-instruct --evidence image --n 20 --prompt-set default --proof-yes-image prescriptions\pres_yes.png --proof-no-image prescriptions\pres_no.png

--------------------------------------------------------------
2. Text-only MedMCQA probe (no images)
--------------------------------------------------------------
Runs a fixed preset model list (edit the MODEL[N]/PROVIDER[N] block
inside the .bat to add/change models), n=5/model by default:

    scripts\model_text_only.bat

--------------------------------------------------------------
3. Local in-process inference (your own GPU, any HF Hub VLM)
--------------------------------------------------------------
vqa_sycophancy_probe_hf_local.py — one script, all 4 evidence modes
via --evidence {image,grounded,none,blind}. --proof-yes-image /
--proof-no-image required for image/grounded only.

EVICTION: this script drops all but the newest image every turn, to
match the NIM backend's 1-image-per-call cap (keeps local vs NIM
comparable). That is NOT how multi-turn VLM dialogue normally works —
for the faithful (non-evicting) "image" condition use the no-evict
script in 3b. "grounded"/"blind" are ablations of the eviction itself.
See EXPERIMENT_SUMMARY.md ("Eviction and the `dual` variant").

Recommended: run_vqa_hf_local_all.bat loops all 4 evidence modes x
all 3 personas = 12 runs per model.

  With --model: just that one model (12 runs).
    scripts\run_vqa_hf_local_all.bat --model google/medgemma-4b-it --n 50 --load-in-4bit

  Without --model: loops the 9 locally-runnable VLMs from
  LOCAL_VLM_CONVERSATIONAL_RANKING.md (Qwen2.5-VL-3B/7B, Qwen3-VL-8B,
  medgemma-4b-it, llava-1.5-7b, HuatuoGPT-Vision-7B,
  MiniCPM-V-2_6, Molmo-7B-D, InternVL3-8B) = 108 runs, sequential. The
  list excludes Llama-3.2-11B-Vision (kept on NIM) and NVLM-D-72B
  (too big for local), and Phi-3.5-vision (Hub modeling code
  incompatible with transformers 5.x); edit MODEL_LIST inside the .bat
  to change it.
    scripts\run_vqa_hf_local_all.bat --n 50 --load-in-4bit --trust-remote-code

--load-in-4bit is not optional on an 8GB card for a ~4B+ model like
medgemma-4b-it — bf16 weights alone are already ~8GB before any KV
cache growth across the 10-turn conversation. 4-bit quantized brings
it down to roughly 3-4GB total, comfortable headroom. --trust-remote-code
is needed for MiniCPM-V / Molmo / InternVL3. Both flags are
global (apply to every model in the loop), so when sweeping the whole
list pass both.

Other flags: --dataset-dir --split --seed --pushback-turns --device
{auto,cuda,cpu} --runner NAME --dry-run (prints every command without
running it — use it first to see the full sweep).

Single-combo manual invocation, if you only want one cell instead of
the full 12:
    .venv\Scripts\python.exe vqa_sycophancy_probe_hf_local.py --model Qwen/Qwen2.5-VL-3B-Instruct --evidence none --n 5 --prompt-set default

    .venv\Scripts\python.exe vqa_sycophancy_probe_hf_local.py --model Qwen/Qwen2.5-VL-7B-Instruct --evidence image --n 20 --prompt-set default --proof-yes-image prescriptions\pres_yes.png --proof-no-image prescriptions\pres_no.png
    .venv\Scripts\python.exe vqa_sycophancy_probe_hf_local.py --model Qwen/Qwen2.5-VL-7B-Instruct --evidence grounded --n 20 --prompt-set default --proof-yes-image prescriptions\pres_yes.png --proof-no-image prescriptions\pres_no.png
    .venv\Scripts\python.exe vqa_sycophancy_probe_hf_local.py --model Qwen/Qwen2.5-VL-7B-Instruct --evidence none --n 20 --prompt-set default
    .venv\Scripts\python.exe vqa_sycophancy_probe_hf_local.py --model Qwen/Qwen2.5-VL-7B-Instruct --evidence blind --n 20 --prompt-set default

Swap --prompt-set to neighbor_nurse_doctor / generic to cover the other
two personas. Swap --model for any other Hub VLM; add --load-in-4bit to
fit bigger models in less VRAM, --trust-remote-code for models with
custom Hub code, --runner NAME to override the auto-detected
username@hostname metadata tag (no longer a folder level, just recorded
in results.json/RESULTS.txt/summary/<model>.md).

3a. dual — positional variant of "image"
--------------------------------------------------------------
vqa_sycophancy_probe_hf_local_dual.py — copy of the above with a 5th
--evidence value, "dual": instead of anchoring the real scan at turn 0
and adding the fake one at turn 1, both are introduced together on
pushback turn 1 (real first). Isolates image ordering/position. Still
evicts like its parent (so nothing shown after turn 1 — that's the
parent's eviction, not "dual"). Report within-model only. Needs a
model with real multi-image support (NOT Llama-3.2-Vision).

    scripts\run_vqa_hf_local_dual.bat --model Qwen/Qwen2.5-VL-7B-Instruct --n 50
    (loops dual x all 3 personas = 3 runs; proof images always required, resolved automatically)

Same --model behavior as run_vqa_hf_local_all.bat: omit it to sweep the
same 10-model list (30 runs; llava-1.5-7b will fail dual — single-image
only — which is expected). Same optional flags otherwise.

3b. no-eviction — SOTA-faithful "image"
--------------------------------------------------------------
vqa_sycophancy_probe_hf_local_no_evict.py — never evicts old images,
matching standard multi-turn VLM dialogue. "image" here = real scan
(turn 0) + fake prescription (turn 1) both stay in context for the
rest of the conversation — the methodologically correct "image"
condition, and the numbers to report for it. Only image/none apply
(grounded/blind are eviction ablations). Output goes to *_noevict
folders so it never mixes with the NIM-comparable evicting runs of
the same name. See EXPERIMENT_SUMMARY.md ("Eviction and the `dual`
variant").

    scripts\run_vqa_hf_local_noevict.bat --model Qwen/Qwen2.5-VL-7B-Instruct --n 20
    (loops image + none x all 3 personas = 6 runs; omit --model to sweep
     the same 10-model list = 60 runs)

Gemma-family models (medgemma-4b-it etc.) are auto-forced to bfloat16
regardless of GPU — no flag needed, the script detects "gemma" in the
model name itself.

--------------------------------------------------------------
Notes
--------------------------------------------------------------
- Output layout (every script, NIM or local): results/<model>/<variant>/<prompt>/
    results.json       - canonical summary + full results, overwritten each run
    RESULTS.txt         - human-readable appended log
    transcripts/<id>.json - per-item checkpoint
  <variant> is image / grounded / no_pres / blind. No separate top-level
  transcripts/ tree anymore, and no <runner> folder level for local runs -
  runner is recorded as metadata inside results.json/RESULTS.txt instead.
- All scripts checkpoint/resume automatically, including vqa_sycophancy_probe_hf.py
  now - safe to re-run the same command after an interruption, already-done
  items are skipped.
